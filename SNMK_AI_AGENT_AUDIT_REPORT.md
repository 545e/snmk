## 3. CrewAI Orchestration Adapter ([core/crewai_adapter.py](file:///C:/Users/krish/SWA/core/crewai_adapter.py))

Multi-agent coordination is mediated through `core/crewai_adapter.py`:
- **`CrewAIAgentConfig`:** Encapsulates role, goal, backstory, tool allowlist, memory toggle, and `max_iter` iteration caps.
- **`CrewAITaskConfig`:** Defines task descriptions, expected structured outputs, and context dependencies.
- **`SNMKCrew`:** Coordinates sequential and hierarchical task execution with cycle guards and timeout enforcement.
- **Pre-Configured Cybersecurity Crew (`create_cybersecurity_pentest_crew`):** Assembles a synchronized triage pipeline:
  1. Senior Reconnaissance Specialist (Amass / Subfinder)
  2. Application Security Auditor (OWASP plugins / SQLi engine)
  3. DevSecOps Remediation Architect (Patch generator / WAF rules)

---

## 4. Agent Safety & Guardrail Enforcement

1. **Restricted Tool Allowlisting:** Agents are restricted to explicitly registered tools; arbitrary command execution is strictly blocked.
2. **Anti-Infinite Loop Protections:** Iteration caps (`max_iter = 15`) and step timeouts terminate runaway agent loops.
3. **No Unvalidated Autonomous Privileged Actions:** Security findings and remediation patches generated by AI agents remain in draft/pending status until confirmed by human-in-the-loop analysts or deterministic scanners.
